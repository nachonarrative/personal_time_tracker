Independent Time Tracker

Start Here

Beginner friendly

This tracker needs two small pieces of information from your browser: timer events and confirmed pay seconds. Nothing gets sent anywhere by this app.

Open browser tools before you work. The timer JSON only appears when the trainer task timer is running and you start, pause, or resume it while Network is recording.

Safe to paste: response or payload JSON. Never paste cookies, request headers, passwords, bearer tokens, or anything that says Authorization.

1

Open Browser Tools

In Chrome or Edge, open trainer platform, then press F12 or Ctrl + Shift + I.

trainer platform F12
2

Go To Network

Click the tab named Network, then turn on Preserve log before you start, pause, or resume the timer.

Elements Network Console
Preserve log ON
3

Filter The Request

Type createTimeTrackingEvent to find timer starts, resumes, and pauses. If the timer was already running before Network was open, that earlier start may not be there.

Filter createTimeTrackingEvent
4

Copy The JSON

Click the request, open Preview or Payload, copy only the JSON, paste it below, then click Import JSON.

{ "taskId" "timeWorkedInSeconds" }

Paste Browser Tool JSON

Local only

Safe Timer Event JSON

Paste this kind of JSON when the timer starts, pauses, or resumes.

{
  "taskId": "example-task-id-123",
  "eventName": "started",
  "createdAt": "2026-06-03T17:16:36.641Z"
}

Safe Confirmed Time JSON

Paste this kind of JSON when trainer platform confirms payable seconds.

{
  "taskId": "example-task-id-123",
  "workerId": "example-worker-id-456",
  "timeWorkedInSeconds": 846
}
